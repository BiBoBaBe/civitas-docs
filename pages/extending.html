A world can declare what it counts, what kinds of situation it has, what verbs it adds, how its narrator writes, and which places have special properties. The engine never learns what any of it means. This page shows each declaration as it is actually written.

A world in code

A code world is a TypeScript file that seeds the same things a card does, with more room: places that nest, schedules with weekday masks and priorities, secrets with trust gates, disclosure rules, ladders of wants, a calendar, a climate, and a voice. Then one line registers it, and the command line and the service open it the same way.

export interface BuiltInWorld {
  id: string;
  name: string;
  opening: string;                 // what the player reads before anybody has spoken
  seed(store: EventStore, branch: BranchId): void;
  player: PersonId;
  opensAt: WorldTime;              // the hour the world is worth walking into
  tick: Omit<TickOptions, "minutes" | "player">;   // ladders, disclosure, the scanner
  voice: VoiceContract;
  residents: readonly PersonId[];  // whose opinions count as "the street"
  secret?: FactId;                 // the thing the world turns on, if it turns on one
  calendar?: Calendar;
  climate?: Climate;
  tells?: readonly RegExp[];       // what the player might say that gives the secret away
  beatMinutes?: number;            // minutes an exchange costs when the narrator does not say
}

The registry exists so that the command line and the service open a world identically. A world that only one of them knows how to start is a world that behaves differently depending on who asked.

Quantities

Money was the first quantity and for a while the only one. Health, stamina, standing and mana are the same shape: a number per person, moved only by events, sometimes conserved, sometimes capped, sometimes coming back on its own. So a world declares what it counts:

declareResource(COIN,    { conserved: true, min: 0 });
declareResource(STAMINA, { conserved: false, min: 0, max: 100, regenPerHour: 6 });
declareResource(MANA,    { min: 0, max: 50, regenPerHour: 3 });

The defaults are the unremarkable ones: floors at zero, no ceiling, no regeneration, not conserved. Conserved is a strong claim, so a world has to make it out loud, and the invariant harness then proves every turn that nothing was minted. Three events move a quantity: granted adds to the world, spent takes away, transferred never changes the total.

Kinds of situation

Seven kinds ship: debt, promise, grudge, attraction, contract, secret, rivalry. They are ordinary declarations, and a world's own kinds stack on top of them. Nothing in the engine knows what a debt is; it knows a debt has a creditor because the declaration said which stance that is.

export const CASTING_KIND = declareThreadKind("casting", {
  aggrievedStances: ["channelling"],   // who is owed something when one breaks
  stakes: 0.7,                          // when a verb opens one without saying
  holdsInPlace: ["channelling"],        // stances that keep somebody where they are
  onBroken: { kind: "grudge", wrongedStance: "aggrieved", atFaultStance: "at fault" },
});

holdsInPlace is worth noticing. Most situations do not keep you anywhere; you can owe a man money from anywhere. Some are a thing you are in the middle of doing, and the tick should not walk you off to the bar halfway through. A world names those stances and the routine stops moving them.

Verbs

A verb is what a tag does: its arguments, its preconditions, and the events it produces. Most new verbs are data, a requirement the graph can already answer and an effect it already knows how to apply. When a mechanic needs logic, the verb is an ordinary function that returns events, and by the time the adjudicator has it there is nothing to tell it apart from a built-in one.

This is the start of a spell-casting verb from the magic system that ships as a worked example, written entirely as world content with nothing patched in the engine:

{
  name: "begin_cast",
  args: { person: "person", spell: "text", cost: "number" },
  help: `<<begin_cast person="NAME" spell="what they are working" cost="NUMBER">> — somebody starts holding a spell. It does nothing until released.`,
  check({ world, at, player, args }) {
    if (args.person === player) return no("that is the player's to decide", "let him decide it himself");
    if (balanceIn(world, MANA, args.person) < args.number.cost) return no(`they only have ${held} mana`, `cast for at most ${held}`);
    if (heldSpell(world, args.person, at)) return no("they are already holding one", "release or drop it first");
    return ok;
  },
  effects(context) {
    return [
      eventInput("spent", at, { resource: MANA, person: caster, amount: cost }, { witnesses: seen }),
      eventInput("node_added", at, { node: makeThread(id, summary, { threadKind: "casting", ... }) }),
      eventInput("edge_added", at, { edge: { type: "INVOLVED_IN", from: caster, to: id, stance: "channelling", ... } }),
    ];
  },
}

Three things to notice. The same authority rule every verb has: the narrator does not decide what the player does with his own hands. The mana is spent up front, so an interruption costs something. And the spell is a situation like any other, so the brief shows it to the narrator without anybody writing a renderer for spells.

Voice

Everything about how the story reads is supplied by the world. Nothing about what is true is:

export interface VoiceContract {
  name: string;
  rules: string;          // rules for the narrator, tuned independently of the brief
  targetWords?: number;   // roughly how long a reply should be
}

The adult switch lives here too, as a rule in the contract rather than a flag in the engine.

Place markers

A place can carry three optional markers, all covered on Places and doors:

FieldMeaning
ownDoorThe place is its own premises for earshot: a flat rather than a room in a gym.
vehicleA place you ride inside, with an optional driver who is present and hears everything, and a seat count.
conspicuous0 to 1, how much it draws eyes. Separate from whether it gets you anywhere.

What stays closed

Event sourcing, temporal links, the fold, branching, rumour diffusion, brief assembly and the invariant harness are the engine. A world does not reach into them. Everything on this page is a declaration the engine reads, which is what keeps a world tradeable and keeps the tests meaningful for every world at once.
